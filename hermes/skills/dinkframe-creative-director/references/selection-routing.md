# Theme and color routing

Treat theme and color as independent controls. Select one theme recipe from the
art-direction playbook, then apply the chosen color recipe below. Change grid,
type behavior, material, lighting, and image treatment between themes—not just
the accent hue.

## Color recipes

- **Black & White:** use tonal depth, texture, and hard value separation. Do not
  introduce chromatic accents.
- **Blue:** choose navy, cobalt, or indigo according to the theme; avoid generic
  blue gradients.
- **Cyan:** use crisp cool light, charcoal structure, and white clarity; keep it
  distinct from ordinary blue.
- **Purple:** choose plum for luxury/editorial, ultraviolet for futuristic, or
  mineral violet for clean directions. Use one restrained warm complement. For
  Clean & Premium, keep the canvas light-led rather than violet-black.
- **Green:** choose forest/emerald for premium, lime for athletic/futuristic, or
  botanical green for tropical. Never tint skin green.
- **Red:** choose oxblood for luxury, crimson for cinematic/athletic, or
  vermilion for editorial energy. Avoid making every red direction a dark arena.
- **Orange:** choose burnt amber for cinematic/premium or safety orange for
  athletic/experimental. Balance it with ink, cream, or cool charcoal.
- **Custom:** preserve the exact supplied value as the signature color and build
  tonal variants around it.
- **Surprise Me:** write `SURPRISE ME` in the prompt. Choose a concept-derived
  three-color palette and state exact hex values. Prefer an unexpected but
  defensible harmony; do not default to black plus neon.

## Surprise theme

When the theme is **Surprise Me**, write `SURPRISE ME` and create one named,
out-of-the-box campaign system from a specific cue in the athlete, tournament
logo, venue, event title, or pickleball geometry. State how the system changes
composition, typography, material language, and image treatment. Avoid generic
stadiums, default cyberpunk, random collage, and effects catalogues. The result
must still feel premium, legible, and suitable for manual sponsor finishing.

When both color and theme are **Surprise Me**, make one coherent decision rather
than two unrelated surprises. Name the concept, state its three-color palette,
and explain the visual logic directly inside the production instructions.
